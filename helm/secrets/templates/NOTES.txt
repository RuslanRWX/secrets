{{ include "secrets.fullname" . }} is installed.

1. Reach the web interface:

{{- if .Values.ingress.enabled }}

   http{{ if .Values.ingress.tls.enabled }}s{{ end }}://{{ .Values.ingress.host }}
{{- else }}

   kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "secrets.fullname" . }} 8080:{{ .Values.service.port }}

   then open http://localhost:8080
{{- end }}

2. The first page is the install wizard. It creates the administrator account.
   Every later user is added from the Users page and must change their password
   at first sign-in.

3. Back up the master key now. Every secret in the database is encrypted with
   it, and nothing can be recovered without it:

   kubectl --namespace {{ .Release.Namespace }} get secret {{ include "secrets.keySecretName" . }} \
     -o jsonpath='{.data.master-key}' | base64 -d; echo

{{- if not .Values.encryption.masterKey }}

   This key was generated by the chart. It is kept across upgrades and is
   retained if you uninstall the release.
{{- end }}
{{- if and .Values.postgresql.enabled (not .Values.postgresql.persistence.enabled) }}

WARNING: the bundled database has persistence disabled. Everything is lost when
the pod restarts. Set postgresql.persistence.enabled=true before real use.
{{- end }}
{{- if not .Values.ingress.tls.enabled }}

WARNING: this application transmits credentials. Terminate TLS in front of it
before exposing it beyond a trusted network.
{{- end }}
